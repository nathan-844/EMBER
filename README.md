# EMBER — Fire Safety Research

EMBER is a research prototype for the 2026 NASA Space Apps challenge
*Flame in Freefall: SI-Powered Fire Safety Insights from Microgravity Combustion Data*.

It ranks NASA Physical Science Informatics (PSI) combustion investigations against a
crew-environment scenario (oxygen, pressure, gravity, airflow, fuel) and is explicit
about what the evidence can and cannot establish.

## Getting started

```bash
npm install
npm run dev
```
